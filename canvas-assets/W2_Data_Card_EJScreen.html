Data Card — EPA EJScreen (MS Coastal Counties Subset)

Used in Week 2 Lab 1. Revisited in Week 12 for spatial autocorrelation.

What is it?

EJScreen is the US EPA's environmental justice screening and mapping tool. For each US Census block group, it reports 12 environmental indicators (like PM 2.5 concentration and proximity to hazardous facilities) alongside 7 socioeconomic indicators (like percent low-income and percent people of color). It also reports 13 EJ Indexes and 13 Supplemental Indexes that combine environmental and demographic information.

Terminology note (teachable moment). In EJScreen versions before ~2.2, the column called PEOPCOLORPCT was called MINORPCT ("percent minority"). EPA renamed it deliberately when they broadened the definition. If you consult any older EJScreen documentation, tutorial, blog post, or AI-generated code snippet and see MINORPCT, that is the same concept — just the outdated column name. In this course we always use the current name PEOPCOLORPCT. This kind of quiet column rename between dataset versions is a common source of code that "worked yesterday, broken today" — which is exactly why the Week 2 data-dictionary habit matters.

For Lab 1 we work with the block groups for the three Mississippi Gulf coastal counties: Hancock, Harrison, and Jackson — roughly 250–300 block groups total.

Version note

EJScreen is updated approximately annually. Always record the specific version you used (e.g., "EJScreen 2024 release, data as of March 2024"). The methodology has changed between versions — comparing values across years is often not valid.

For Lab 1 we use the current release (whichever is live when the semester starts) and pin the version in the notebook.

Coordinate reference system

The downloaded file is a geodatabase or CSV with FIPS codes; when joined to a TIGER/Line block-group boundary file, geometry comes in NAD83 (EPSG:4269), geographic coordinates in decimal degrees. For any area calculations in Lab 1 we reproject to NAD83 / Mississippi Transverse Mercator (EPSG:6508) which preserves area in the state.

Attributes and measurement scales

Note: EJScreen has 60+ columns. Below are the ones we actually use in Lab 1; the full data dictionary is linked in the technical documentation. Attribute names below match the current release.

Identifier columns

Column Type Scale Notes
ID text Nominal 12-character census block group FIPS code. Always store as string to preserve leading zeros.
STATE_NAME text Nominal e.g., "Mississippi"
ST_ABBREV text Nominal e.g., "MS"
CNTY_NAME text Nominal e.g., "Harrison County"

Demographic / socioeconomic indicators

Column Type Scale Units / Notes
ACSTOTPOP numeric Ratio Total population (ACS 5-year estimate)
PEOPCOLORPCT numeric Ratio Fraction of population that is people of color (0–1). Formerly MINORPCT in EJScreen ≤ v2.1.
LOWINCPCT numeric Ratio Fraction of population that is low-income (0–1)
LINGISOPCT numeric Ratio Fraction of population in linguistic isolation
LESSHSPCT numeric Ratio Fraction of adults with less than high school education
UNDER5PCT numeric Ratio Fraction of population under age 5
OVER64PCT numeric Ratio Fraction of population over age 64

Environmental indicators

Column Type Scale Units / Notes
PM25 numeric Ratio Annual average PM 2.5 concentration, µg/m³
OZONE numeric Ratio Ozone summer seasonal average of daily maximum 8-hour concentration, ppb
DSLPM numeric Ratio Diesel particulate matter, µg/m³
PTRAF numeric Ratio Traffic proximity indicator (count of vehicles × distance)
PNPL numeric Ratio Proximity to National Priorities List (Superfund) sites
PRMP numeric Ratio Proximity to Risk Management Plan facilities
PTSDF numeric Ratio Proximity to Treatment/Storage/Disposal Facilities
PWDIS numeric Ratio Wastewater discharge indicator
PRE1960PCT numeric Ratio Fraction of housing built pre-1960 (lead paint proxy)

Percentile indicators (state and national)

Column Type Scale Notes
P_PM25 / P_OZONE / P_DSLPM / ... numeric Ordinal State/national percentile (0–100). Ordinal because percentile intervals don't reflect equal intervals in the underlying variable.
P_D_PM25 / P_D_OZONE / ... numeric Ordinal Demographic-weighted EJ Index percentiles

Known caveats

  • Percentages are stored as fractions, not percents. PEOPCOLORPCT = 0.42 means 42%. Multiply by 100 for display; don't for calculations that expect fractions.
  • Missing values are represented as -999 in some columns and as null/blank in others. Both need to be converted to NaN before any math.
  • Small-population block groups may have suppressed demographic values (privacy protection) or huge ACS margins of error.
  • Percentiles are computed against a national or state distribution; a block group at the "50th state percentile" is average for Mississippi, not average nationally.
  • Some environmental indicators are proximity-based and don't account for real-world barriers (rivers, highways) that could reduce actual exposure.
  • EJScreen is a screening tool, not a regulatory determination. Values suggest where to look further; they do not by themselves prove disparate impact.
  • The block-group boundary file (TIGER/Line) is separate from the EJScreen attribute table. You must join by FIPS code to make maps.

Why we use it in Weeks 2 and 12

Week 2: EJScreen is a rich real-world dataset with variables at every measurement scale, well-documented quality issues, and immediate connection to environmental questions. It teaches the "audit the data before you touch it" habit without being overwhelming.

Week 12: The environmental indicators — especially PM 2.5, diesel PM, and traffic proximity — show clear spatial patterns at the block-group level. This makes EJScreen the ideal dataset for teaching Moran's I, Geary's C, and LISA cluster mapping.

Capstone: For any student interested in environmental justice, air quality, or exposure disparities, EJScreen is a strong capstone dataset. It's on the curated 417 list.
