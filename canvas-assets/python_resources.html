What You Actually Need to Know

The good news: this course uses a small, consistent slice of Python. You do not need to be a software developer. You need to be able to:

  • Open a Colab notebook and run cells in order.
  • Read code that someone else wrote and modify a small piece (change a filename, swap a column name, adjust a number).
  • Read an error message and figure out the general kind of problem it's describing.
  • Use an AI tool to explain unfamiliar code — and audit the explanation.
  • Look up library documentation when something's not clear.

Notice what's not on that list: writing loops from scratch, writing functions, understanding decorators or generators, managing environments locally, or anything involving classes. This is a stats-with-Python course, not a Python-programming course.

Python 101 Refresher — The Fastest Path

If you've never seen Python, or it's been a while, spend 60–90 minutes here before Lab 0.

The absolute minimum in one page

# 1. Variables and types
x = 5              # integer
y = 3.14           # float
name = "hurricane" # string
active = True      # boolean

# 2. Lists (ordered collections)
storms = ["Katrina", "Ida", "Michael"]
storms.append("Ivan")     # add to end
print(storms[0])          # "Katrina" — Python indexes from 0

# 3. Dictionaries (key-value pairs)
storm = {"name": "Katrina", "year": 2005, "cat": 5}
print(storm["year"])      # 2005

# 4. Loops
for s in storms:
    print(s)

# 5. If-else
wind = 130
if wind > 155:
    category = 5
elif wind > 130:
    category = 4
else:
    category = 3

# 6. Functions — you'll USE many, WRITE few in this course
def celsius_to_fahrenheit(c):
    return c * 9 / 5 + 32

print(celsius_to_fahrenheit(25))  # 77.0

# 7. Importing libraries — how we bring in pandas, geopandas, etc.
import pandas as pd            # standard shorthand
import numpy as np
import matplotlib.pyplot as plt

# 8. Reading a file (the pattern you'll use in every lab)
df = pd.read_csv("filename.csv")   # df = "DataFrame"
print(df.head())                   # show first 5 rows

That's ~90% of the Python you'll ever type in this course. The rest is looking up specific functions in pandas or geopandas.

Common gotchas that trip up newcomers

  • Indentation matters. Python uses indentation, not braces, to group code. Four spaces per level. Colab handles this automatically if you use its editor.
  • Indexing starts at 0. storms[0] is the first storm, storms[1] is the second.
  • print() is your friend. Any time you're not sure what a variable holds, print it.
  • The error message is usually right. Read it top to bottom, then look at the LAST line — that's usually the actual error.

Learning With AI (the responsible way)

Generative AI is one of the best on-ramps to Python if you use it well. Here are prompts that work.

When you don't understand a code cell

"Explain what this Python code does line by line, as if I've never seen pandas before. Point out anything a beginner would trip on: [paste the code]"

When an error message baffles you

"I got this Python error in Google Colab: [paste the entire error, including the traceback]. What is the most likely cause? What should I check first?"

When you want to modify sample code

"Here's a code snippet that computes X. I want to instead compute Y using the same DataFrame. What single change do I need to make? [paste the code and describe Y]"

When you're writing something from scratch

"Write the minimum Python code, using pandas, that reads a CSV, drops any row where the 'pm25' column is missing, and computes the mean. Add a comment on each line explaining what it does. Keep it as short as possible."

The verify step — always

Never trust AI-generated code without running it. AI frequently invents functions or gets syntax subtly wrong. The pattern to build:

  1. Read the code the AI gave you.
  2. Predict what it will do.
  3. Run it.
  4. Check whether it did what you predicted.
  5. If not, ask the AI why, but also read the actual documentation of the function it used.

This "predict → run → check → look up" loop is the durable skill.

AIs that are especially good for Python

  • Gemini in Colab — literally built into the notebook environment. Click the "Gemini" icon in a Colab toolbar.
  • ChatGPT (free tier is fine) — https://chatgpt.com
  • Claude — https://claude.ai
  • GitHub Copilot — free for students with a .edu email. https://education.github.com

All four are fluent Python tutors. All four will occasionally invent Python function names that don't exist. The verify step matters no matter which one you use.

Reference — the "just enough" cheatsheets

pandas — the DataFrame

A DataFrame is a spreadsheet-like table. Every row is an observation, every column is a variable.

import pandas as pd

# Load a CSV
df = pd.read_csv("data.csv")          # basic
df = pd.read_csv("data.csv", dtype={"ID": str})   # keep ID as string (FIPS codes)

# Look at it
df.head()          # first 5 rows
df.tail()          # last 5 rows
df.shape           # (rows, cols)
df.columns         # column names
df.dtypes          # column data types
df.describe()      # summary stats per numeric column
df.info()          # size + non-null counts

# Select
df["pm25"]                        # one column (a Series)
df[["pm25", "ptraf"]]             # two columns (still a DataFrame)
df.iloc[0]                        # first row by position
df.loc[df["pm25"] > 10]           # rows where PM 2.5 > 10

# Missing data
df.isna().sum()                          # count NaN per column
df["pm25"] = df["pm25"].replace(-999, np.nan)   # fix sentinel values
df.dropna(subset=["pm25"])               # drop rows missing PM 2.5

# Group and aggregate
df.groupby("CNTY_NAME")["pm25"].mean()   # mean PM 2.5 per county
df.groupby("CNTY_NAME").size()           # count of block groups per county

# Compute new columns
df["log_traf"] = np.log(df["ptraf"] + 1)

# Save
df.to_csv("out.csv", index=False)

geopandas — the GeoDataFrame

A GeoDataFrame is a pandas DataFrame with a geometry column that holds spatial data.

import geopandas as gpd

# Load
gdf = gpd.read_file("blockgroups.geojson")   # GeoJSON or shapefile

# Look at it
gdf.head()
gdf.crs            # coordinate reference system
gdf.geometry       # the geometry column
gdf.plot()         # quick map

# Reproject
gdf = gdf.to_crs("EPSG:6508")     # to MS Transverse Mercator (equal-area for MS)

# Join with a pandas DataFrame (attribute join)
merged = gdf.merge(df, left_on="GEOID", right_on="ID", how="inner")

# Spatial select
subset = gdf[gdf.intersects(some_polygon)]

# Save
gdf.to_file("out.geojson", driver="GeoJSON")

matplotlib — quick plots

import matplotlib.pyplot as plt

# Histogram
fig, ax = plt.subplots(figsize=(7, 4))
ax.hist(df["pm25"].dropna(), bins=20, edgecolor="white")
ax.set_title("PM 2.5 across MS coastal block groups")
ax.set_xlabel("Annual mean PM 2.5 (µg/m³)")
ax.set_ylabel("Number of block groups")
plt.tight_layout()
plt.show()

# Bar chart
by_county = df.groupby("CNTY_NAME")["ptraf"].median()
by_county.plot.bar()

# Scatter
plt.scatter(df["pm25"], df["ptraf"])
plt.xlabel("PM 2.5"); plt.ylabel("Traffic proximity")

# Save a figure to a file
plt.savefig("fig.png", dpi=150, bbox_inches="tight")

Google Colab specifics

  • Save your work early. File → Save a copy in Drive. Colab does NOT automatically save changes to a notebook you opened from a URL.
  • Shift + Enter runs the current cell.
  • Runtime → Restart session wipes all variables. Use when things get weird.
  • Runtime disconnects after ~90 minutes of idle. You lose in-memory variables (but not saved code). Re-run cells from the top.
  • Upload a file to the current session with the folder icon on the left sidebar.
  • Access your Google Drive with the "Mount Drive" button on the left sidebar.
  • !command in a cell runs a shell command (!ls, !pip install foo).
  • %pip install is the notebook-friendly way to install a package.
  • Gemini in Colab: click the sparkles icon in the toolbar to open the AI panel. It sees the current notebook and can generate or explain code.

When you get stuck — the escalation ladder

  1. Read the error message. Really read it. Nine times out of ten it names the exact line and the exact problem.
  2. Add print() statements before the line that errored to see what the variables actually contain.
  3. Ask an AI tool using one of the prompt templates above. Try to understand the fix, not just copy it.
  4. Search the specific error phrase on Google or Stack Overflow. Include the library name (e.g., "pandas KeyError CNTY_NAME").
  5. Look up the function in the official documentation — pandas.pydata.org, geopandas.org, pysal.org. AI tools sometimes invent function signatures; the docs don't.
  6. Post in the course Q&A discussion forum with the error message and what you've tried. Classmates and I will help.
  7. Email me for a Teams appointment if you're truly blocked. I would much rather help you now than accept a late lab later.
