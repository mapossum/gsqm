Welcome

Welcome to GHY 417/517 — Quantitative Methods in GIS. This first week has one goal: get you set up and oriented so weeks 2 through 15 run smoothly. There is no reading quiz this week and Lab 0 is ungraded (completion-based).

Statistics can feel abstract when it lives inside a textbook. In this course we ground every method in a real environmental question drawn from the Gulf South — hurricane tracks, wetland loss, water quality, environmental justice, biodiversity — so you always know why you're doing what you're doing.

Learning Objectives

By the end of this week you will be able to:

  1. Explain what quantitative methods contribute to geographic inquiry and how spatial data creates challenges that non-spatial statistics don't fully address.
  2. Set up and verify the course technology environment (Google Colab, the Python spatial-stats stack, and ArcGIS Online if available).
  3. Describe the course's expectations around AI use, and identify the key differences between using AI as a tutor and using AI to bypass learning.
  4. Introduce yourself to the class and locate the key parts of the Canvas course structure.

Do you need to already know Python?

No. This course does not require prior Python experience. It moves faster if you have some, so I've built a Python & Colab Resources page (Python_Resources.md) with:

  • A 60-second self-assessment so you know where you stand.
  • A one-page "everything you need in Python for this course" summary.
  • Recommended free tutorials (2 to 6 hours each — pick one).
  • pandas / geopandas / matplotlib "just enough" cheat sheets.
  • Colab-specific tips (save-to-Drive, Gemini panel, session timeouts).
  • Templates for asking AI tools to explain unfamiliar code.
  • A "when you're stuck" escalation ladder.

If your self-assessment lands at 0–2 yes, budget an extra 2–4 hours in Weeks 1 and 2 for the primer. You will absolutely catch up — thousands of people have started similar courses from zero — but the on-ramp is real. Contact me early if you want a check-in.

If your self-assessment lands at 3+ yes, treat Python_Resources.md as a reference to bookmark and return to when you need it.
